Bhavishya Gyani V38 — User Dashboard Astrologers Relationship Fix

Problem fixed:
Could not find a relationship between 'astrologers' and 'profiles' in the schema cache.

Cause:
The User Dashboard astrologer API was trying to use a PostgREST relationship join:
profiles!astrologers_id_fkey
The current project stores astrologer profile fields directly in public.astrologers,
so this relationship is not required and may not exist in Supabase's schema cache.

Changed file:
lib/api/astrologers.js

The patch now reads approved/unblocked astrologers directly from public.astrologers.
It does NOT change the database schema and does NOT reset/delete any data.

Apply this patch on top of the current Bhavishya Gyani project.
Do NOT run supabase/setup.sql for this code-only fix.
