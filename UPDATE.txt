Bhavishya Gyani V39 PATCH — Chat button conversationId error fix

Fixes the "conversationId required" error when a user taps Chat from an astrologer profile.

Cause: chat.html was sending action="chat", while /api/chat expects action="request" for a new chat request. The API then fell through to the action handlers that require conversationId.

Changes:
- public/chat.html: maps new=chat to action=request before POST.
- lib/api/chat.js: accepts legacy action=chat as an alias for request, while preserving V37 chat-list ordering fix.

Apply on top of V38. Do NOT run supabase/setup.sql. Do NOT replace the whole project.
