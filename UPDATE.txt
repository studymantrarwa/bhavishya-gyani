Bhavishya Gyani V37 — Astrologer Chat List Order Fix

Problem fixed:
The Astrologer Panel was showing:
"failed to parse order (coalesce(last_message_at,created_at).desc)"

Cause:
Supabase PostgREST does not accept coalesce(...) inside the order parameter.

This patch changes only:
lib/api/chat.js

It uses supported last_message_at / created_at ordering with a safe fallback.

Apply:
1. Keep your current Bhavishya Gyani project.
2. Replace only lib/api/chat.js with the file from this ZIP.
3. Deploy to Vercel again.
4. Do NOT run supabase/setup.sql.
5. No database reset is required.

This is a code-only patch; existing login, Kundli, chats, accounts and data are preserved.
