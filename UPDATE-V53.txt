V53 — FAST REALTIME CHAT + KUNDLI SHARE

Apply this patch on top of the current V52 project.

Changes:
- User can share a saved Kundli from an active chat.
- Astrologer receives the Kundli card in the chat and can tap “Kundli खोलें”.
- Shared Kundli opens through the existing full Kundli renderer (`/kundli.html`), so D1/D9, planets, houses, Nakshatra/Pada, Dasha, Gochar, Sade Sati, Ashtakavarga, Yog/Dosha and other calculation details use the same existing Kundli display system.
- Astrologer is allowed to view the shared full Kundli; user access remains supported.
- Realtime chat no longer reopens/reloads the whole chat on every conversation UPDATE, reducing visible latency and reconnect churn.
- Broadcast remains the primary instant delivery path; database save continues in the background through the existing messages API.
- Fallback resync runs only while realtime is disconnected, rather than polling every 200ms while connected.

No database schema change.
Do NOT run supabase/setup.sql.
