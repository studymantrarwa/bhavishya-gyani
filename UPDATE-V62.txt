Bhavishya Gyani V62 — Stable Latest-Message Chat + 200ms Fallback Sync + Typing

Apply this patch on top of the current V61 project.

Changes:
- Fixes astrologer/user chat jumping back to the beginning/old position during reconnect sync.
- Reconnect fallback no longer calls openChat(), so the whole message list is not cleared/re-rendered repeatedly.
- When a new message arrives, the chat stays at the latest message.
- Initial chat open scrolls to the latest message.
- Fallback message resync runs every 200ms ONLY while realtime is disconnected/erroring.
- Prevents overlapping 200ms sync requests.
- Realtime remains the primary path when connected; no 200ms database polling while realtime is healthy.
- Typing indicator remains realtime on both sides and now stops promptly after a short idle period, blur, or send.
- No database schema/setup SQL changes.

Do NOT run supabase/setup.sql.
